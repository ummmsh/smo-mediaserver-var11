# smo-mediaserver-var11

Имитационная модель системы массового обслуживания (СМО) для медиасервера видеоконференций. Участники конференции отправляют видеокадры, сервер перекодирует их на нескольких узлах. Пока все узлы заняты, кадры ждут в ограниченном буфере. При переполнении самый старый кадр сбрасывается как устаревший.

| Элемент СМО | Сущность бизнес-домена | Назначение |
|---|---|---|
| Источник (ИБ) | Участник видеоконференции | Формирует бесконечный поток видеокадров |
| Закон генерации (ИЗ1) | Пуассоновский поток кадров | Интервалы между поступлениями кадров распределены экспоненциально |
| Буфер (Д1ОЗ3) | Приёмный буфер медиасервера | Хранит кадры, пока все вычислительные узлы заняты. Новый кадр занимает первую от начала свободную ячейку без сдвига очереди |
| Прибор (ПЗ2) | Узел перекодирования | Перекодирует кадр в несколько качеств. Время обработки распределено равномерно на заданном отрезке |
| Дисциплина отказа (Д1ОО3) | Механизм сброса устаревших кадров | При переполнении удаляет самый старый кадр и записывает на его место новый |
| Выбор прибора (Д2П1) | Алгоритм выбора вычислительных узлов | Направляет кадр на свободный вычислительный узел с наименьшим номером |
| Выбор заявки (Д2Б2) | Алгоритм выбора кадра из буфера | Выбирает на обработку последний поступивший кадр |
| Отображение результатов (ОР1) | Подсистема статистики | Формирует сводную таблицу |
| Отображение динамики (ОД2) | Подсистема мониторинга | Показывает формализованную схему с текущим состоянием элементов |
| Заявка | Видеокадр | Единица обслуживания, содержащая номер участника, номер кадра и время поступления. Перекодируется либо сбрасывается как устаревший |
